# Proyecto de Métodos Numéricos
Los métodos numéricos son procedimientos y algoritmos iterativos que nos permiten obtener soluciones aproximadas mediante operaciones básicas

El presente proyecto fue desarrollado en lenguaje **JAVA** y tiene como finalidad el desarrollo y programación de los métodos numéricos con interfaz gráfica (**JavaSwing**)

## MÉTODOS IMPLEMENTADOS

Los métodos desarrollados se dividen en 3 apartados

## SOLUCIÓN NUMÉRICA DE ECUACIONES DE UNA SOLA VARIABLE
- Método de bisección
- Método de falsa posición
- Método de Newton
- Método de la secante
## SOLUCIÓN DE SISTEMAS DE ECUACIONES LINEALES
- Método de Gauss
- Método de Jacobi
- Método de Gauss-Seidel
## FACTORIZACIÓN LU
- Método Cholesky
- Método Doolittle
